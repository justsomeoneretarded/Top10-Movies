# Bundled fonts

All fonts are from the Google Fonts repository (https://github.com/google/fonts) and are licensed under the
SIL Open Font License 1.1, which allows commercial use, embedding in videos and images, and redistribution
with the license text. License files are included next to each font.

| File | Family | Use |
|---|---|---|
| `Anton-Regular.ttf` | Anton | Rank numbers, thumbnail headlines |
| `BebasNeue-Regular.ttf` | Bebas Neue | Titles in rank cards |
| `Montserrat-Variable.ttf` | Montserrat (variable weight) | Small text: years, end screen, captions |
