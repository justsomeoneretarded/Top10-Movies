# Recorded music

Titan, Celestial and Aurora by Scott Buckley (https://www.scottbuckley.com.au), licensed under Creative Commons Attribution 4.0 International: https://creativecommons.org/licenses/by/4.0/. Official source pages and file hashes are in catalog.json. Files are excerpts re-encoded to Vorbis. Production normalizes, repeats with crossfades and ducks the music. Attribution is automatically added to description.txt and sources-and-credits.txt. These audio files are not covered by the repository code license.

Official sources:
- https://www.scottbuckley.com.au/library/titan/
- https://www.scottbuckley.com.au/library/celestial/
- https://www.scottbuckley.com.au/library/aurora/
